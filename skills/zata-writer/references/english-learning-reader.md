# 分级英语知识读本（双目标学习）

用于读者希望**提升英语的同时掌握一个知识主题**的教材、分章读本或 PDF 书稿。主题可以是 AI、工程、科学、人文或其他可核验的知识领域。它不是把一篇中文文章逐句翻译成英语。

## 先定义两类学习结果

动笔前明确：读者的英语水平（优先用 CEFR，如 B1）、已有主题知识、阅读语言、中文辅助程度、预计学习时间，以及读完后要能解释或完成什么。

每个单元同时服务两件事：

- **主题目标**：读者能说明一个概念、比较方案、画出流程或完成一个小设计。
- **英语目标**：读者能读懂本单元的英文，掌握少量主题词汇，并用一个语言结构表达自己的理解。

把 CEFR 水平当作写作目标，不宣称已经通过 CEFR 认证。技术准确性不能为了简单英语而被改错；遇到难概念时，用短句、例子和中文提示降低阅读负担，并保留必要的限定条件。

## 双语与分级原则

- 英文承担主要讲解，句子以常用词和清晰关系为主。用 `first`、`because`、`if`、`however` 等连接词说明顺序、原因、条件和区别。
- 专业词首次出现时，用简单英语解释；需要时在旁边补充中文释义。中文用于解开概念难点，不逐段重复翻译英文。
- 语言点从本单元真实需要中选，例如过程顺序、因果、比较、条件、义务或不确定性。给一个与主题有关的自然例句，再让读者仿写。
- 让读者接触真正的主题内容，不把所有文字都降成空泛短句。新概念先给直观例子，再逐步加入术语、流程和边界。
- 控制词汇量，优先选理解主题和复述主题所需的词；例句要自然、准确，不能只是把词典释义换个位置。

## 推荐书稿结构

按主题复杂度和篇幅选择，不强制每个项目使用相同页数：

1. **前置页**：适用读者、双重学习目标、主题地图、使用方法和复习计划。
2. **学习单元**：每章围绕一个可解释的概念或可完成的设计任务。
3. **综合案例**：把多个概念放进同一场景，展示选择、取舍和失败处理。
4. **综合练习**：让读者把概念迁移到新场景，而不只是重复定义。
5. **词汇与答案**：汇总主题词汇，给理解题和设计题提供简洁的参考答案。
6. **来源**：标明主题地图、事实依据、示例依据以及需要随时间更新的资料。

### 学习单元的常用组件

可以合并相近组件，以保持节奏和版面密度；但不要为了压页数删掉理解一个主题所必需的内容：

- 一段目标水平的英文讲解，明确核心概念及其作用。
- 一条中文设计提示，或一个小图示，帮助读者抓住难点。
- 概念结构：解决什么问题、目标是什么、适用于什么场景。
- 有序工作流或机制图，以及一个具体的 worked example。
- 适用条件、与相近概念的区别、常见失败和修正方法。
- 约 4 个核心词汇：英文、中文释义和语境例句。
- 一个相关的语言点和仿写例句。
- 两道理解题和一个迁移练习。答案页按单元编号逐题对应。

一页课程可以把以上内容排成紧凑学习页；复杂章节可以扩成多页。密度来自减少重复、合并导航页、缩短空白和增强信息组织，不靠把字号压到难以阅读。若读者要求“内容更密”，先增加有用的例子、比较、错误分析或练习，再调整版式。

## 练习与答案的一致性

- 理解题要能从本章读到的内容回答，不依赖未解释的外部知识。
- 设计题要给出可操作的任务，例如“给三个步骤并说明检查点”，不要只写“谈谈你的看法”。
- 答案页必须按相同的单元编号回应每一道题；开放式设计题给出一个示例，并说明其他合理答案也可以。
- 如果版面容不下完整答案，可提供关键点，但不能让题目与答案标题或编号错位。

## 事实依据与视觉材料

先用原始材料确定主题范围，再为技术细节查项目源码、官方文档、论文或标准。项目 README 可用于理解目录和主题地图，但不能自动替代实现或时效性能力的核验。区分“源项目的说法”“官方规范”和“本书为了教学编写的例子”。为协议、产品能力等易变内容保留准确来源和核查日期。

优先使用解释机制的流程图、结构图、比较表和练习表。图示必须帮助读者理解概念或判断；不要为满足文章插图数量添加装饰图。复用外部图前核对许可与来源，无法确认时自行绘制简明图示。

## PDF 与交付检查

用户要 PDF 时使用可用的 PDF 专项 Skill 完成排版、逐页渲染和视觉检查。重点检查：

- 英文、中文和符号都能正确显示，表格没有超出纸张边界。
- 学习单元的字级适合打印；标题、流程、词汇和练习一眼可区分。
- 每个问题在答案页有对应内容；目录、页码、章节名和封面描述与实际结构一致。
- 来源链接可读且能点击；最终 PDF 的页数和输出文件与交付说明相符。

交付时简要说明覆盖的主题、英语目标、包含的练习与答案，以及实际做过的渲染检查；不要把没有验证的 CEFR 等级或技术实现细节说成已验证。
